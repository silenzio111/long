# Academic Books & Scientific Papers Catalog

This library hosts translated digital textbooks, monographs, and academic papers processed with **PDFMathTranslate** and LLM agent gateways.

All documents feature **side-by-side bilingual reading** by default, with instant toggles for **Chinese Only** and **English Only** modes.

## 🛠️ Reader Features & Keyboard Shortcuts

- **Synchronized Paging**: Left (English) and right (Chinese) panes stay in 1:1 lockstep when turning pages.
- **Focused Modes**: Switch to "Chinese Only" or "English Only" at any time for concentrated study.
- **Keyboard Shortcuts**: Press `←` for Previous Page, and `→` for Next Page.
- **Direct Navigation**: Enter any page number in the toolbar input box and press Enter to jump immediately.
- **Range Request Streaming**: Pages are fetched on demand via HTTP 206 byte-range requests without requiring the entire multi-megabyte file to be downloaded upfront.
