# 翻译书籍与学术文献文库

本专栏存放利用 **PDFMathTranslate** 与大语言模型智能体网关批量翻译的电子书籍与学术文献。

所有文献默认支持**中英双栏对照阅读**（左侧英文原稿，右侧中文译稿），并提供**仅中文模式**与**仅英文模式**无缝切换。

## 🛠️ 阅读器特性与快捷键

- **双栏同步**：中英双栏模式下，两栏实时保持同页码联动。
- **单栏专注**：随时点击顶部“仅中文”或“仅英文”按钮，单栏放大沉浸阅读。
- **快捷翻页**：在页面内任意位置按键盘方向键 `←` 翻至上一页，按 `→` 翻至下一页。
- **快速跳转**：在工具栏页码输入框中直接输入目标页数回车即可直达。
- **按需加载机制**：阅读器基于 HTTP 206 范围分块请求，仅在读者翻阅到对应页面时按需加载当前页数据，无需等待整本数十兆文件下载完成。
